# CellDeathDetect

Method for detection and classification of cell death in Quantitative Phase image sequences.

Data for testing of this code are available at: https://doi.org/10.5281/zenodo.2601562

## Citation

If you use this code or dataset, please cite:

Vicar, T., Raudenska, M., Gumulec, J. & Balvan, J. The Quantitative-Phase Dynamics of Apoptosis and Lytic Cell Death. *Scientific Reports* **10**, 1566 (2020). https://doi.org/10.1038/s41598-020-58474-w

## Additional documentation

- `DATA_NOTES.md` gives notes on the deposited data.
- `CODEBOOK.md` describes the annotation terms in the workbooks. It was prepared in November 2026 from the original annotation files.
- `acquisition_metadata.csv` gives per-sequence acquisition details. Exposure and gain are given as stored by the acquisition software, taken from the first recorded frame of each experiment.
